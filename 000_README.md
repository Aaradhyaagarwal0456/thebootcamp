# NIELIT AI/ML Bootcamp – Python, Data Science & Machine Learning

Welcome to my first GitHub repository! 

This repository contains the practical work and projects I completed during a 4-day AI/ML Bootcamp conducted by **NIELIT (National Institute of Electronics & Information Technology)**.

This bootcamp was my first hands-on experience with GitHub, Python-based data analysis, machine learning, and computer vision. The repository contains the concepts, practical exercises, datasets, and projects covered throughout the bootcamp.

---

## 📚 Bootcamp Overview

### Day 1 – Python Basics 

Covered the fundamentals of Python programming, including:

- Variables and data types
- Input and output
- Conditional statements
- Loops
- Basic Python programming
- Practical coding exercises

---

### Day 2 – NumPy, Pandas & Data Visualization 📊

Worked with popular Python libraries used in data science:

- NumPy arrays and operations
- Pandas DataFrames
- Creating and working with datasets
- Mean, median, mode and standard deviation
- Matplotlib
- Data visualization and graphs
- Basic data analysis

---

### Day 3 – Machine Learning 🤖

Worked on practical machine learning concepts using datasets and CSV files.

Topics and projects included:

- Creating and working with CSV datasets
- Student Performance dataset
- Data preprocessing
- Supervised Machine Learning
- Basic ML model implementation
- Reinforcement Learning concepts
- Understanding model training and prediction

---

### Day 4 – NLP, Word Cloud & Computer Vision 🖼️

The final day focused on practical projects involving text and image processing.

#### Word Cloud Project

Created a personalized **Hobbies & Interests Word Cloud** using Python and NLP-related libraries.

Concepts used:

- Text processing
- Tokenization
- Stopword removal
- Word frequency
- WordCloud generation
- Data visualization

#### PhotoShop – Image Processing Using OpenCV

Created a basic image processing project using OpenCV.

Implemented operations such as:

- Image reading
- Image resizing
- Cropping
- Horizontal and vertical flipping
- Image rotation
- Grayscale conversion
- Brightness adjustment
- Contrast adjustment
- Blur
- Sharpening
- Edge detection
- Saving processed images
